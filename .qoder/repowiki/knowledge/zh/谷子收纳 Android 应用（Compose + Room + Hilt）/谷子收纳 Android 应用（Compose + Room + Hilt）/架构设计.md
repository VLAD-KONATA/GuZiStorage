模块采用典型的分层结构：
- UI 层：`MainActivity` 作为 `ComponentActivity` 入口，通过 `setContent` 挂载 Compose 树，当前仅展示 `Greeting` 占位界面；主题封装在 `ui/theme/Theme.kt`。
- 领域层：`domain/model/Item.kt`、`Transaction.kt` 为纯 Kotlin data class，不依赖 Android API，由 Repository 负责与 Entity 互转。
- 数据层：`data/local/entity/*` 为 Room `@Entity` 映射类，`AppDatabase` 声明三张表（items、transactions、preset_options），多选字段以管道符分隔字符串存储并通过 `PipeListConverter` 转换；`dao/*` 暴露 `Flow` 查询接口；`repository/*` 统一封装 CRUD 并对外暴露响应式 `Flow<List<Domain>>`，同时承担 Entity ↔ Domain 转换职责。
- 依赖注入：`di/AppModule.kt` 通过 Hilt `@Module` + `@InstallIn(SingletonComponent)` 提供 `AppDatabase` 单例与各 DAO，`GuZiStorageApp` 标注 `@HiltAndroidApp` 完成初始化，UI 组件通过 `@AndroidEntryPoint` 获取依赖。
- 构建配置：`app/build.gradle.kts` 启用 KSP（Room 注解处理器）与 kapt（Hilt 编译器），Kotlin/JVM 目标 17，minSdk 26，使用 BOM 管理 Compose 版本。
