- 领域模型与数据库实体之间通过 `toEntity()` / `fromEntity()` 工厂方法显式转换，Repository 层统一执行该转换并对外暴露领域对象。
- 所有只读查询返回 `Flow<T>` 响应式流，写入操作使用 `suspend` 函数，Repository 将 DAO 的 Entity 流 map 为领域模型流再向上抛出。
- 多选/集合型字段在 Entity 中以管道符 `|` 分隔的 String 存储，统一通过 `PipeListConverter.fromList` / `toList` 进行序列化/反序列化。
- Hilt 依赖注入遵循 `@Module` + `@InstallIn(SingletonComponent)` 提供全局单例，DAO 通过 `@Provides` 从 `AppDatabase` 实例化后注入 Repository。
