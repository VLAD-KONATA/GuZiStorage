# 目前的部分开发命名规则

本文档用于记录项目讨论和开发过程中约定的页面、场景称呼，避免后续需求表达时出现歧义。

## 页面称呼

| 场景 | 推荐称呼 | 说明 |
| --- | --- | --- |
| 默认以 IP 分组时打开 App 看到的首页 | **分组首页** | 也可以叫“收藏首页”。它不是谷子列表，而是第一级分组入口。默认第一级是 IP，所以显示为 IP 分组。 |
| 点击某个 IP 分组后，直接看到该 IP 下所有谷子的列表/网格 | **谷子一览页** | 当前路径已经到最终层级时使用这个称呼。比如默认只有 `IP名` 一级分组时，点进“名侦探柯南”后就是“谷子一览页”。 |
| 点击单个谷子后看到详细信息、图片、交易入口的界面 | **谷子详情页** | 这个最直观，后续说“详情页加字段/改布局/加按钮”都不会歧义。 |
| 自定义多级分组时，中间层级看到的“下一层分组卡片”页面 | **子分组页** | 例如分组规则是 `IP -> 角色 -> 种类`，点进某个 IP 后，看到“按角色分组”的界面，就叫“子分组页”。 |
| 多级分组走到最后一层后，看到具体谷子的界面 | **谷子一览页** | 例如 `IP -> 角色 -> 种类`，点进 IP、角色、种类之后，看到具体谷子列表，就是“谷子一览页”。 |

## 当前术语约定

1. **分组首页**：App 第一屏，第一级分组入口。代码上主要对应 `HomeScreen`。
2. **子分组页**：多级分组中的中间层，展示下一层分组。代码上对应 `GroupScreen` 的非最终级状态。
3. **谷子一览页**：某个分组路径下的具体物品列表。代码上对应 `GroupScreen` 的最终级状态，或搜索切换到物品列表时的状态。
4. **谷子详情页**：单个物品详情。代码上对应 `DetailScreen`。
5. **交易记录页**：某个谷子的购入/卖出记录列表。代码上对应 `TransactionScreen`。
6. **谷子编辑页 / 新增谷子页**：添加或编辑物品。代码上对应 `AddItemScreen`。

## 目前数据库字段规则

这里按当前代码口径记录谷子记录表字段规则。“业务必填”指用户手动新增/编辑或导入时必须提供有效值，不完全等同于数据库列是否可空。

| 字段 | 代码字段 | 数据库列 | 业务必填 | 1 对多 | 数据/转换规则 |
| --- | --- | --- | --- | --- | --- |
| ID | `id` | `id` | 自动生成 | 否 | 主键，新建时由 `IdGenerator.generate()` 生成。ZIP 图片目录也用它关联。 |
| 中文名称 | `nameCn` | `name_cn` | 是 | 否 | 手动新增/编辑、导入时都不能为空。 |
| 日文/英文名称 | `nameEn` | `name_en` | 否 | 否 | 空值存 `null`。 |
| IP名 | `ipName` / `ipNames` | `ip_name` | 是 | 是 | 默认一级分组字段；领域层用 `ipNames` 解析为列表，数据库仍存在 `ip_name` 列并用 `|` 拼接；手动新增/编辑、导入时至少 1 个值。 |
| 出品商 | `producer` / `producers` | `producer` | 否 | 是 | 空值存 `null`；多值用 `|`；可分组、筛选、搜索。 |
| 出品地 | `originPlaces` | `origin_places` | 否 | 是 | 前端/领域层是 `List<String>`；数据库用 `|` 拼接。读写时 trim 并去空。 |
| 发售形式 | `saleFormat` | `sale_format` | 否 | 是 | 非必填；数据库可为 `null`，领域层用空列表表示未填写；多值用 `|`。 |
| 售卖方式 | `sellMethod` | `sell_method` | 否 | 否 | 可空；表单空值保存为 `null`；详情页为空不展示。 |
| 价格 | `price` | `price` | 否 | 否 | 数据库存字符串；表单里拆成金额 + 货币，保存时合成，详情页格式化展示。 |
| 发售日期 | `releaseDate` | `release_date` | 否 | 否 | 保存/导入时会规范成 `YYYY-MM` 风格。 |
| 种类 | `category` / `categories` | `category` | 否 | 是 | 空值存 `null`；多值用 `|`；可分组、筛选、搜索。 |
| 尺寸 | `sizes` | `sizes` | 否 | 是 | `List<String>` 与 `|` 拼接字符串互转；详情页展示原始值；搜索/筛选/分组时会忽略中英文括号及其中内容，例如 `56mm（圆吧唧）|78×53mm（方吧唧）` 按 `56mm`、`78×53mm` 处理。 |
| 材质 | `materials` | `materials` | 否 | 是 | `List<String>` 与 `|` 拼接字符串互转。 |
| 相关角色 | `characters` | `characters` | 是 | 是 | 至少 1 个值；多值用 `|`。多级分组时，一个谷子可进入多个角色分组。 |
| 柄图种类 | `artTypes` | `art_types` | 是 | 是 | 当前仍是必填，至少 1 个值；多值用 `|`。 |
| 状态 | `status` | `status` | 自动默认 | 否 | 默认 `无伤`；表单选择 `无伤/有伤`。 |
| 伤情详情 | `damageDetails` | `damage_details` | 否 | 是 | 仅状态为有伤时有意义；多值用 `|`。导入时状态列可兼容旧写法。 |
| 版本 | `version` | `version` | 否 | 否 | 表单默认 `初贩`；详情/列表显示名里非 `初贩` 会加版本前缀。不可作为分组字段，但仍可搜索/筛选/排序。 |
| 数量 | `quantity` | `quantity` | 自动默认 | 否 | 只有正整数保存为实际数量；空、非数字、负数、0 都转成 `0`，表示暂未拥有。 |
| 原袋 | `originalBagQuantity` | `original_bag_quantity` | 否 | 否 | 空/非法/负数为 `null`；`0` 表示明确无原袋；正整数表示原袋数量。 |
| 参考链接 | `referenceLinks` | `reference_links` | 否 | 是 | `List<String>` 与 `|` 拼接字符串互转；详情页可点击；不参与分组/筛选/搜索。 |
| 图片路径 | `imagePaths` | `image_paths` | 否 | 是 | 只存相对路径；真实图片在 `filesDir/images/{itemId}/`。导入时按文件名排序写入。 |
| 备注 | `note` | `note` | 否 | 否 | 空值存 `null`；可搜索/筛选。 |
| 扩展 JSON | `extraJson` / `extraAttributes` | `extra_json` | 否 | 预留 | 当前基本固定写 `{}`，领域层的 `extraAttributes` 暂未真正读写。 |
| 创建时间 | `createdAt` | `created_at` | 自动生成 | 否 | 新增时写入当前时间；默认谷子列表按 `created_at DESC`。 |
| 更新时间 | `updatedAt` | `updated_at` | 自动生成 | 否 | 编辑保存时刷新；可在排序里选择“更新时间”。 |

当前需要用户填写/导入时必须存在有效值的字段只有：`中文名称`、`IP名`、`相关角色`、`柄图种类`。

其中 `IP名`、`相关角色` 和 `柄图种类` 是必填的 1 对多字段，至少要有一个值。
